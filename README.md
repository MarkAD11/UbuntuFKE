# Ubuntu Fraternity KE Website

A modern, responsive website for Ubuntu Fraternity KE - a brotherhood dedicated to preserving and sharing Kenyan values, traditions, and stories.

## 🌟 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Separation of Concerns**: Properly organized CSS and JavaScript files
- **Accessibility**: Semantic HTML and proper ARIA labels
- **SEO Optimized**: Meta tags and structured content for better search visibility
- **Interactive Elements**: Smooth navigation, form validation, and modal dialogs

## 📁 Project Structure

```
/
├── index.html              # Homepage (main entry point)
├── about.html              # About Us page
├── blogs.html              # Blog listing page
├── contact.html            # Contact information page
├── events.html             # Events and upcoming activities
├── gallery.html            # Photo gallery
├── membership.html         # Membership registration
├── partnership.html        # Partnership opportunities
├── privacy.html            # Privacy policy
├── css/
│   └── styles.css          # Main stylesheet
├── js/
│   └── main.js             # Main JavaScript file
└── README.md               # Project documentation
```

## 🛠️ Customization

### Adding New Pages
1. Create new HTML file
2. Copy the navigation structure from existing pages
3. Add your content within the appropriate section
4. Link to the new page in the navigation menu

### Modifying Styles
- Edit `css/styles.css` for global styles
- Use CSS custom properties for easy color changes
- Follow the existing naming conventions

### Adding JavaScript Functionality
- Add new functions to `js/main.js`
- Follow the existing code structure
- Use the notification system for user feedback
